New Thread Screen Alternatives

Current Problem

The current "New Thread" screen is just a basic project picker list. It doesn't help users understand what they can do or make the experience feel purposeful.

Design Goals

  • - Guide users to meaningful interactions
  • - Surface available agents & capabilities
  • - Reduce cognitive load
  • - Match iOS design patterns
Alternative 1

Task-Focused Start

Instead of asking "which project?", this design asks "what do you want to do?" - putting the user's intent first.

Key Design Decisions

  • + Task input field at the top (immediate action)
  • + Common task shortcuts as chips
  • + Project selection is secondary
  • + Recent projects visible but not dominant

Best For

Users who know what they want to do but might not know which project/agent to use.

Alternative 2

Smart Suggestions

AI-powered suggestions based on project context, recent activity, and common workflows. Like Siri Suggestions for TENEX.

Key Design Decisions

  • + Contextual suggestions from recent activity
  • + One-tap to start common tasks
  • + Shows relevant agent for each task
  • + "Continue where you left off" option

Best For

Power users with established workflows who want quick access to frequent tasks.

Alternative 3

Quick Action Sheet

A bottom sheet approach similar to iOS share sheets. Quick to access, quick to dismiss, with clear action categories.

Key Design Decisions

  • + Native iOS bottom sheet pattern
  • + Icon-based action grid
  • + Recent projects as horizontal scroll
  • + Swipe down to dismiss

Best For

Quick, lightweight interactions when users want to start something fast without leaving context.

Alternative 4

Agent-First Picker

Focus on WHO you're talking to, not which project. Great for users who have built relationships with specific agents.

Key Design Decisions

  • + Agents as primary navigation
  • + Shows agent capabilities & specialties
  • + Online status and recent activity
  • + Project selection happens after agent

Best For

Users who think in terms of capabilities ("I need the debugger") rather than projects.

Alternative 5

Conversation Composer

A full composition experience like starting an email. Combines all inputs in one cohesive view with rich formatting options.

Key Design Decisions

  • + Email/iMessage compose pattern
  • + To: field with agent/project tokens
  • + Subject/title for thread organization
  • + Attachment and context options

Best For

Complex tasks that need proper setup - detailed bug reports, feature requests, or multi-agent coordination.

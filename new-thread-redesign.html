New Thread & Input Redesign

Design Rationale

  • 1. Agent selector in new thread picker with project context
  • 2. Full-screen compose sheet for visibility
  • 3. Clear attachment previews before sending
  • 4. Collapsed state shows agent chip, expands on tap

Key Changes

  • + Agent selection in new thread flow
  • + Sheet-based compose for more space
  • + Better attachment visibility
  • + Online status indicators

New Thread with Agent

Combined project + agent selection in a single flow. User picks a project, then immediately sees available agents for that project.

Flow

  1. 1. User taps + to start new thread
  2. 2. Sheet shows projects with their online agents
  3. 3. Tapping project shows agent picker inline
  4. 4. Selected agent is p-tagged in first message

Benefits

  • + User knows who they're talking to upfront
  • + Shows online status before starting
  • + One fewer step than separate selection

Compose Sheet

Full-screen sheet for composing messages. Opens when tapping the input bar. Much more space to see what you're typing and manage attachments.

Key Elements

  • - Agent chip shows who you're talking to
  • - Large text area for message composition
  • - Toolbar at bottom with actions
  • - Character/nudge options easily accessible

Benefits

  • + Much more typing space
  • + See full message before sending
  • + Better keyboard experience
  • + Easier to add attachments

Collapsed Input Bar

The input bar in its collapsed state at the bottom of the chat. Shows the selected agent, tapping opens the compose sheet.

Collapsed State Shows

  • - Agent avatar + name chip
  • - Placeholder text
  • - Quick action buttons (image, plus)

Interaction Flow

  1. 1. Tap input area = Opens compose sheet
  2. 2. Tap agent chip = Opens agent selector
  3. 3. Tap image = Opens photo picker
  4. 4. Tap + = Shows more options menu
